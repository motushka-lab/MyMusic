MYMUSIC PORTABLE WINDOWS
========================

Цель:
Получить один самостоятельный файл:

    dist\MyMusic.exe

после сборки.

Сборка:
1. На Windows установи Node.js LTS.
2. Дважды нажми build.bat.
3. Подожди окончания сборки.
4. Готовый portable-файл будет:
   dist\MyMusic.exe

После этого MyMusic.exe можно копировать на другой Windows-компьютер
и запускать без установки MyMusic.

ВАЖНО:
Этот архив содержит исходники и скрипт сборки. Сам Windows .exe
не включён, потому что сборка Electron portable должна выполняться
на Windows/Windows CI.
